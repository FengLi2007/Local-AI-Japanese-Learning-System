目前网上的普遍的相关的针对日语学习（包括电子词典，语法解析）的软件/系统课程等几乎都是收费的，且AI在没有标准的、固定的相关知识库的时候，对于日语的解析和音调的标明有相对英语的较大失误和错误。稍有基础的日语爱好者只能自己看书，问通用AI，或者看网上免费课程。这是本项目的灵感来源。
本项目主要是致力于构建一个完整的，来源权威的，以兴趣为学习驱动力和导向的自由的小型私人自用学习平台，让初学了一些的有一点基础的人能够不再跟着系统的课程，而是能够自由地根据自己的兴趣，不论是文献/歌曲/台词/小说，进行合理，收获满满的学习。本项目还希望能够做到一定程度的私人定制化，就像是一个长期与你相处教学的老师/同学一样的角色。
注意，这个项目不适合日语学术研究。
